# Bank System (C++)

A console-based bank management system written in C++ to practice
Object-Oriented Programming and the STL.

## Features
- [ ] Create an account
- [ ] Deposit / withdraw
- [ ] Transfer between accounts
- [ ] Show account details
- [ ] Save / load data from file

## Concepts Practiced
- Classes and objects, encapsulation
- Inheritance and polymorphism (e.g. SavingsAccount, CurrentAccount)
- STL: vector, map, ...

## How to Run
```bash
g++ bank_system.cpp Account.cpp -o bank_system
./bank_system
```

## Project Structure
```
bank-system/
├── bank_system.cpp
├── Account.h
└── Account.cpp
```
